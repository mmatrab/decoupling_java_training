# Decoupling Java Training

This project is focused on training and understanding decoupling principles in Java. It aims to provide practical examples and exercises for learning how to design modular and maintainable code by reducing dependencies between components.

## About This Project

This repository was developed within an academic context, serving as a resource for students and educators to explore the concept of decoupling in software design. The exercises and examples are designed to be easily understandable and adaptable for educational purposes.

Feel free to explore and contribute!
